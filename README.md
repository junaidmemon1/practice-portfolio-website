# 🌐 Modern Portfolio Website

A modern and responsive portfolio website built using **HTML**, **CSS**, and **JavaScript**.

This project was created as a frontend development practice project to improve UI design skills, responsive layouts, and interactive web development concepts.

The website features a clean user interface, smooth design structure, and fully responsive layout optimized for different screen sizes.

---

# 🚀 Features

- 🎨 Modern and Clean UI Design
- 📱 Fully Responsive Layout
- ⚡ Smooth User Experience
- 💻 Built with Pure HTML, CSS, and JavaScript
- 🌐 Cross-Browser Compatible
- 📂 Organized Project Structure
- ✨ Interactive Frontend Elements

---

# 🛠️ Technologies Used
